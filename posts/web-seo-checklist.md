구글 검색 결과의 첫 페이지에 블로그가 노출되기 위해서는 검색엔진 로봇(Googlebot)이 사이트를 쉽게 크롤링하고 인덱싱할 수 있도록 **SEO(Search Engine Optimization)** 설정을 정교하게 다듬어야 합니다. 

이 글에서는 모던 웹 프레임워크 기반 블로그를 위한 온페이지(On-Page) SEO 핵심 요소를 정리합니다.

---

## 1. 시맨틱 HTML과 태그 계층 구조

검색엔진 로봇은 웹페이지를 읽을 때 HTML 태그의 의미론적(Semantic) 중요도를 판단합니다.

### 1.1 Heading H1 ~ H6의 올바른 사용
- 하나의 페이지에는 오직 하나의 `<h1>` 태그만 존재해야 합니다. 보통 블로그 포스트 상세 페이지에서는 **글 제목**이 `<h1>` 역할을 맡습니다.
- 소제목은 내용의 위계에 따라 `<h2>` 및 `<h3>` 순으로 작성해야 하며, 계층 구조를 건너뛰어서는 안 됩니다. (예: `<h2>` 다음에 바로 `<h4>`로 넘어가지 말 것)

### 1.2 시맨틱 요소 배치
- 페이지 헤더는 `<header>`, 하단 영역은 `<footer>`, 글 본문 영역은 `<article>` 태그로 감싸 크롤러에게 문서 구조를 명확히 선언해 주어야 합니다.

---

## 2. 메타 태그(Meta Tags) 설정

검색엔진 결과 페이지(SERP)에 보여지는 제목과 요약본을 정의하고, SNS 공유 시의 카드 뷰를 제어하는 오픈그래프(OpenGraph) 메타 태그는 필수입니다.

### 2.1 핵심 메타 정보
- **Title**: 페이지의 핵심 키워드를 전면에 배치하고 60자 내외로 작성합니다.
- **Description**: 포스트 본문을 매력적으로 요약한 120자 내외의 설명을 제공하여 클릭률(CTR)을 높입니다.

### 2.2 오픈그래프 및 트위터 카드
- 페이스북, 카카오톡, 트위터(X) 등에서 링크를 공유할 때 카드 형태의 썸네일 이미지를 띄울 수 있도록 `og:title`, `og:description`, `og:image` 정보를 정밀하게 배치합니다.

---

## 3. 사이트맵(Sitemap)과 robots.txt

구글 서치콘솔(Google Search Console)에 등록할 사이트맵과 크롤링 권한을 명시하는 robots.txt는 블로그 전체의 로드맵 역할을 합니다.

### 3.1 동적 사이트맵(sitemap.xml) 생성
블로그에 글을 새로 올릴 때마다 수동으로 sitemap.xml을 고치는 것은 매우 비효율적입니다. Next.js에서는 `app/sitemap.ts` (또는 `app/sitemap.js`) 파일을 활용해 빌드 타임 또는 요청 타임에 포스트 목록을 순회하여 최신 XML 형태의 사이트맵을 동적으로 자동 생성할 수 있습니다.

### 3.2 검색 엔진 수집 요청
사이트맵 주소를 구글 서치콘솔과 네이버 서치어드바이저에 제출하여, 검색 로봇이 주기적으로 사이트맵을 읽고 새 글을 빠르게 인덱싱할 수 있도록 설정하세요.
