이 포스트는 **데키.Log**에 글을 쓸 때 활용할 수 있는 마크다운(Markdown) 예시 파일이자 가이드입니다. 
새 글을 작성하실 때 이 파일(`.md`)의 형식을 그대로 복사해서 새 이름으로 저장하신 뒤 내용만 바꾸어 글을 작성해 보세요.

---

## 1. 포스트 메타데이터 설정 (Frontmatter)

모든 마크다운 포스트 파일 맨 위에는 대시 3개(`---`)로 감싸진 메타데이터 영역인 **프론트매터(Frontmatter)**가 반드시 포함되어야 합니다.

- **title**: 블로그 글의 큰 제목입니다.
- **date**: 글을 작성한 날짜입니다. 최근 날짜 순으로 메인 페이지에 정렬됩니다. (`YYYY-MM-DD` 형식)
- **category**: 포스트의 카테고리입니다. 메인화면의 필터 탭에 자동으로 추가됩니다.
- **tags**: 검색 엔진 및 하단 메타 데이터에 매핑될 태그 리스트입니다.
- **description**: 메인 화면 카드 뷰에 노출될 포스트 요약글입니다.

---

## 2. 자주 사용하는 마크다운 본문 문법

데키.Log에 세련되게 입혀진 본문 스타일을 적용하기 위한 주요 마크다운 표기법입니다.

### 2.1 제목 계층 구조 (Heading)
본문의 소제목을 정의할 때 하이픈/샵(`##` 또는 `###`)을 사용합니다.
- `## 소제목`은 H2 타이틀로 렌더링되며, 우측 스티키 목차(TOC)에 **주요 메뉴**로 나타납니다.
- `### 세부제목`은 H3 타이틀로 렌더링되며, 우측 목차에 **들여쓰기된 서브 메뉴**로 나타납니다.

> **주의**: H1(`# 제목`)은 블로그 시스템이 포스트 제목을 렌더링할 때 이미 사용하므로, 본문 내부에서는 사용하지 않는 것이 SEO(검색엔진 최적화)에 좋습니다.

### 2.2 인용구 (Blockquote)
단락 맨 앞에 `>` 기호를 붙이면 강조나 인용에 알맞은 부드러운 인디고 컬러의 인용 블록이 만들어집니다.

> "배움은 멈추지 않는다. 코딩은 결국 생각하는 방법을 훈련하는 과정이다."
> — 개발자 격언 중

### 2.3 강조 (Formatting)
텍스트를 두껍게 만들거나 기울일 때는 다음과 같이 표기합니다.
- **굵게 표시하기**: 텍스트 양쪽에 별표 두 개(`**굵은 텍스트**`)를 감싸 줍니다.
- *기울여 쓰기*: 텍스트 양쪽에 별표 한 개(`*기울인 텍스트*`)를 감싸 줍니다.
- `인라인 코드`: 키보드 숫자 1번 왼쪽에 있는 백틱 기호(`\`코드\``)로 감싸면 문장 중에 코드 키워드를 강조할 수 있습니다.

## 3. 코드 블록 및 리스트 서식

개발 지식을 기록하기 위한 코드 표현과 목록 태그 사용법입니다.

### 3.1 소스 코드 블록 (Syntax Highlighting)
백틱 세 개(\`\`\`)를 사용해 코드 영역을 선언합니다.

```javascript
// 예시 자바스크립트 함수
function greet(name) {
  console.log(`안녕하세요, ${name}님! 데키.Log에 오신 것을 환영합니다.`);
}

greet('데키');
```

### 3.2 순서 없는 목록 (Unordered List)
하이픈(`-`) 또는 별표(`*`)를 한 칸 띄우고 작성합니다.
- 첫 번째 항목입니다.
- 두 번째 항목입니다.
  - 들여쓰기를 두 칸 하면 하위 항목 목록이 구성됩니다.
- 세 번째 항목입니다.

### 3.3 순서 있는 목록 (Ordered List)
숫자와 마침표(`1.`)를 사용하여 순서를 나열합니다.
1. 첫 번째 순서입니다.
2. 두 번째 순서입니다.
3. 세 번째 순서입니다.
